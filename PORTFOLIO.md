# SMM Analytics Platform — AI-Powered Marketing Intelligence

## Обзор

Веб-платформа сквозной аналитики для школы сыроделия с 12 каналами в соцсетях (Instagram ×4, YouTube ×2, Telegram, VK, TikTok, Дзен, MAX ×2). Собирает данные из 6 источников, считает метрики по единым правилам и формулирует выводы через GLM-5.3 с режимом рассуждений.

**Живая версия:** [anazanaxus.pythonanywhere.com](https://anazanaxus.pythonanywhere.com)

## Ключевые решения

### 1. Релей через GitHub Actions
Бесплатный PythonAnywhere блокирует исходящие запросы к большинству доменов. Вместо платного прокси — GitHub Actions работает бесплатным релеем: 4 раза в сутки запускается workflow, который собирает данные с LiveDune/GetCourse, генерирует GLM-отчёты и отправляет всё в приложение через token-protected API.

### 2. Append-only история метрик
Каждое значение метрики — отдельная строка в `metric_snapshots` с временем получения. Ничего не перезаписывается: при конфликте используется самое свежее значение на день. Это даёт полную аудит-цепочку (клик по числу → вся история изменений) и защищает от случайной потери данных при сбое сбора.

### 3. Единое правило «наша метка»
UTM-фильтр (`utm.is_ours`): метка наша, если стоит наша campaign ИЛИ наш medium. Применяется везде — от KPI-карточек до AI-контекста. Рекламные кабинеты (yandex, fb_ads) исключаются из бизнес-цифр и показываются отдельным блоком.

### 4. AI с гарантированной достоверностью
Схема: источники → база → математика → проверки → нейросеть только формулирует. GLM-5.3 получает JSON с рассчитанными числами и отвечает на вопросы с режимом рассуждений (до 60 секунд). AI-контролёр проверяет отчёты на сходимость сумм и корректность процентов.

### 5. Self-audit (экран «Аудит»)
13 автопроверок, выполняемых при открытии страницы: демо-остатки, дубли метрик, свежесть источников, сходимость KPI с независимым пересчётом из сырых таблиц, воронка GC, висячие записи. Зелёный итог = цифрам можно доверять.

### 6. Детектор накрутки (экран «Качество аудитории»)
Скор 0–100 по 4 категориям: ERR против нормы платформы, аномалии прироста без охвата, подозрительная ровность вовлечённости, соотношение охват/подписчики. Прозрачные флаги с цифрами — можно проверить руками.

## Экраны (24)

**Ядро:** Обзор (KPI + чипы площадок + утренний GLM-бриф) · AI SMM (чат с GLM-5.3, markdown-рендеринг, селектор периода) · Интеллект (предиктор охвата по каналу, тепловые карты, тренды) · Аудит данных (13 автопроверок)

**Каналы:** Каналы (сводный балл 0–100) · Качество аудитории (детектор накрутки + демография TikTok) · Контент (пагинация, ТОП-10/худшие-10) · Календарь (планер публикаций)

**Деньги:** Регистрации (UTM-разрезы, только наши метки) · Продажи (воронка GC, когорты удержания, продуктовые/пробные)

**Аналитика:** Отчёты AI (недельные/месячные с контролёром) · Сравнение периодов · Конкуренты · Гипотезы (A/B с автопроверкой) · Цели (KPI-планы с прогрессом)

**Инфраструктура:** Импорт (TikTok .zip, Дзен .xlsx, CSV) · Комментарии (GLM-классификация на боли/возражения/идеи, автосбор YouTube) · Настройки (вебхуки GetCourse с панелью проверки)

## Импортеры

| Формат | Что парсит |
|---|---|
| TikTok Studio .zip | Дневные метрики, подписчики с приростами, активность по часам, демография |
| Дзен .xlsx | Публикации (592 шт.) с показами/открытиями/дочитываниями |
| «ПЛАН-ОТЧЁТ» .xlsx | Охваты каналов, лиды с UTM, подписчики (листы «Итоги недели», «Лиды») |
| YouTube API | Видео + статистика + комментарии (автосбор + GLM-классификация) |
| Универсальный CSV | Метрики каналов, регистрации |
