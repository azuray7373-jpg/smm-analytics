# SMM Аналитика — 11 каналов + GetCourse + AI-отчёты

Прод: https://anazanaxus.pythonanywhere.com (free-тариф, без карты; продлевать «Run until 3 months» раз в 3 месяца).

## Что внутри
- Дашборд: 7 экранов — Всё вместе, Каналы (11 аккаунтов, Δ к прошлому периоду), Контент
  (фильтры + ТОП-10/худшие-10 + авто-сравнение содержания), Регистрации (UTM→канал→CV),
  GetCourse (воронка, заказы/оплаты, новичок/старичок, входящая/исходящая, график по дням),
  Комментарии (вопросы/боли/возражения/идеи, импорт CSV), AI-аналитика.
- Показатели: ERR, ER, CV, CTR открытий, дочитывания, прирост, рост аудитории;
  недельные (пн–вс) и календарные месячные срезы; месячные проценты всегда из месячных абсолютов.
- История изменений метрик (append-only, статусы OK/MISSING/…), MISSING-уведомления.
- AI: классификация контента, аномалии, недельный/месячный отчёт с УСИЛИТЬ/ИЗМЕНИТЬ/УБРАТЬ,
  «месяц простыми словами», AI-контролёр. LLM подключается ключом в Настройках; без ключа —
  встроенный аналитик на тех же числах.

## Данные GetCourse
Прямой доступ с free-хостингов закрыт (прокси), поэтому работает релей:
GitHub Actions (4 раза в сутки) → Export API ГК → POST /api/ingest (токен в секретах репо).
Формат ГК — колоночный (info.fields + info.items), UTM в полях utm_source / order_utm_source /
gc_system_user_utm_source. Ручной запуск: Actions → GetCourse sync relay → Run workflow.
Рекомендуемое развитие: процессы-вебхуки в ГК («Вызвать URL») прямо в /api/ingest — реалтайм без лимитов.

## Демо-данные
Каналы и демо-статистики создаются при первом старте (SMM_DEMO=1, SMM_DEMO_DAYS).
Демо-регистрации помечены префиксом demo_ и исключены из CV/воронки — реальные цифры не разбавляются.
