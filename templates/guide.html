Экраны

📊 Всё вместе

Главные KPI всей системы за выбранный период и динамика по дням (охват, взаимодействия, регистрации). Каждый показатель снабжён бейджем изменения к предыдущему периоду той же длины (например, неделя к прошлой неделе). Наведите курсор на карточку — увидите формулу расчёта. Ниже — свежий AI-вывод недели с проверкой AI-контролёра.

📡 Каналы

Сравнение всех 11 аккаунтов: подписчики, прирост, охват, ERR/ER/CV и Δ к прошлому периоду. Клик по числу подписчиков открывает историю изменений метрики (что приходило, когда и из какого источника). Клик по названию канала — детальная страница с графиками и материалами. Instagram считаются по четырём аккаунтам отдельно — не объединяйте их в уме.

🎬 Контент

Все опубликованные материалы и их эффективность. Фильтры: период, аккаунт, платформа, формат, рубрика, тип (продающий/экспертный), тема, полнотекстовый поиск. Пресеты «ТОП-10 по ERR» и «Худшие 10» + автоматическое сравнение: чем лучшие отличаются от худших (длительность, CTA, рубрики). Ниже — сводки «по рубрикам» и «по форматам»: средний охват и ERR единицы контента — это готовый ответ «что масштабировать». Кнопка «CSV» выгружает таблицу.

📝 Регистрации

Путь UTM-источник → канал → регистрации → CV из охвата. Демонстрационные регистрации помечены и исключены из расчётов — здесь только реальные данные. График по дням помогает видеть связку контент → регистрации.

🛒 GetCourse

Деньги: воронка регистрации → заказ → оплата с конверсиями, суммы принятых оплат, разрезы новичок/старичок (первый ли это заказ контакта) и входящая/исходящая заявка (с UTM-меткой или без), статусы заказов, топ товаров, заказы по UTM, последние заказы. Данные приходят релеем GitHub Actions (4 раза в сутки) и/или мгновенными вебхуками.

💬 Комментарии

Импорт CSV комментариев из кабинетов площадок → автоматическая классификация: вопросы, боли, возражения, страхи, идеи тем, намерения купить/зарегистрироваться, позитив, негатив. ТОП-списки недели попадают в AI-отчёт.

🤖 AI-аналитика

Выводы недели и месяца, аномалии, кнопки: переанализировать контент, сформировать отчёты. Работает на Gemini (бесплатные квоты) с автоподменой модели при перегрузке; без ключа — встроенный аналитик на тех же числах.

📄 Отчёты

Архив недельных/месячных отчётов с рассчитанными данными и проверкой контролёра. Неделя — строго пн–вс, месяц — календарный; месячные проценты всегда считаются из месячных абсолютов, никогда как среднее недельных.

⬆️ Импорт / ✍️ Ручной ввод / ⚙️ Настройки

Импорт CSV выгрузок (статистика каналов и регистрации). Ручной ввод — дневные метрики со статусом MANUAL и «ручной контекст периода» (продукт, цель, KPI, события — AI учитывает его и не противоречит). Настройки — ключи источников, AI и готовые URL вебхуков GetCourse.

Источники данных и приоритеты

Приоритет по ТЗ: официальный API → официальный CSV → браузер-робот → ручной ввод. Сейчас подключены: GetCourse (релей + вебхуки), YouTube (ключ в Настройках), CSV-импорт, ручной ввод.

Статусы данных: OK (получено), MISSING (источник не дал), NOT_AVAILABLE (метрики нет на платформе), ERROR (ошибка), MANUAL (внесено вручную), ESTIMATED (оценка). Ноль и «нет данных» — принципиально разные вещи: NULL никогда не превращается в 0.

История изменений: значения не перезаписываются. По каждому числу хранится, что пришло, когда, из какого источника и каким запуском — ответ на вопрос «почему в отчёте было 3 280 000, а теперь 3 310 000» всегда есть (клик по подписчикам на «Каналах»).

GetCourse: как настроить мгновенные данные

1) Релей (уже работает): GitHub Actions 4 раза в сутки забирает пользователей/заказы/оплаты за 5 дней и заливает в приложение. Ручной запуск: GitHub → репозиторий smm-analytics → Actions → GetCourse sync relay → Run workflow.

2) Вебхуки (мгновенно, без очередей): в Геткурсе создайте три процесса с операцией «Вызвать URL» — готовые адреса на экране «Настройки». Событие (регистрация/заказ/оплата) появляется в приложении через секунды.

Правила разметки: «входящая» = заказ с заполненным utm_source (пришёл из трафика), «исходящая» = без метки (менеджер/рассылка). «Новичок» = первый заказ контакта в истории, «старичок» = повторный.

AI-аналитика: принципы достоверности

Схема по ТЗ: источники → сырые данные → база → математика → проверки → нейросеть → выводы. AI не считает и не придумывает цифры: он получает уже рассчитанный JSON и только формулирует управленческие выводы. Запрещено выдумывать числа, заменять NULL нулём, утверждать причинность (пишем «вероятный фактор»). Данных нет — пишем «Недостаточно данных для вывода».

AI-контролёр проверяет каждый отчёт перед публикацией: сверяет проценты с абсолютами, ловит строковые метрики и несходимость подписчиков с приростом.

Аномалии ищет математика (падение охвата >30%, ERR >20%, аномальный вклад одного ролика), AI только объясняет вероятные факторы.

Автоматика

Ежедневно 03:00 — сбор данных и маркировка MISSING; 04:00 — синхронизация GetCourse (если сеть доступна); понедельник 06:00 — недельный отчёт; 1-е число 07:00 — месячный. Внешний планировщик: /cron?token=… (токен = SECRET_KEY сервера). Продление PythonAnywhere: раз в 3 месяца кнопка «Run until 3 months» в дашборде.

FAQ

С чего начать работу? 1) Настройте вебхуки ГК (Настройки → URL). 2) Впишите ключ YouTube. 3) Импортируйте CSV Лайфдюн по каналам (Экран «Импорт», формат указан там же). 4) Внесите «ручной контекст» недели. 5) Нажмите «Сформировать вывод недели».

Почему на главной «MISSING»? Это честная маркировка метрик, по которым нет автоматического источника. Закройте импортом/ручным вводом — статусы исчезнут.

Почему регистраций меньше, чем в ГК? Демо-регистрации исключены из расчётов; период фильтрации — календарный. Проверьте фильтр дат сверху страницы.

Безопасны ли ключи? Ключи хранятся в env сервера и GitHub Secrets, в публичном коде их нет.
