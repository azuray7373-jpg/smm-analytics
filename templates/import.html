Импорт CSV (официальные выгрузки)

Схема приоритета по ТЗ: официальный API → официальный XLSX/CSV → браузер-робот → ручной ввод. Этот экран — второй уровень.

Что понимает этот экран:

  • 📱 TikTok — .zip архивы из TikTok Studio → Аналитика → Экспорт (Overview и Followers). Дневные просмотры/лайки/комментарии/репосты, подписчики с приростами, активность по часам, демография — всё разложится по каналу TikTok автоматически.
  • 📰 Дзен — .xlsx из Дзен Студии → Статистика → выгрузка публикаций. Каждая публикация попадёт в «Контент» (со ссылкой), дневные суммы показов/открытий/дочитываний — в метрики канала.
  • 📋 «ПЛАН-ОТЧЁТ. Статистики СММ» — ваш еженедельный xlsx (листы «Итоги недели», «Лиды», подписчики).
  • 🔢 CSV — универсальный формат (описан ниже).

Повторная загрузка безопасна: новые значения дописываются в историю, в расчётах используется самое свежее.

XLSX «ПЛАН-ОТЧЁТ. Статистики СММ» разбирается автоматически: листы «Итоги недели*»/«Охваты месяц» → охваты каналов, «Лиды*» → регистрации с UTM (ОТКРЫТЫЙ УРОК→openlesson, ОТВЕТЫ→otvety; метки post/canal-anons/bot/botVL2/story/taplink/gayd/shapka), «ТГ подписчики»/«вк» → подписчики. Если в листах лидов даты без года — укажите год в поле выше (лиды без дат сохраняются сегодняшним числом).

Формат универсального CSV

Статистика канала:
date,channel_id,metric,value[,status]
2026-08-20,5,reach,15000,MANUAL

Регистрации:
date,registrations,utm_source,utm_medium,utm_campaign,landing,count
2026-08-20,yes,instagram,reels,webinar_sept,/reg,42

channel_id смотрите на экране «Каналы» (id в URL истории метрики) или в настройках.
